Entry for the [make.fun](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) competition "One Letter for Your Day".

`main.py` (Python 3.13, pure standard library, deterministic, no network)
writes exactly one letter to `entry.txt`: **D** — for *doomscrolling*,
thumbing an endless feed in the small hours, phone glow on your face,
one more swipe and then sleep. Vivid, funny, and true to a real day.

Run it with:

```sh
python3 main.py
```

It prints the letter and the SHA-256 of `entry.txt`.
